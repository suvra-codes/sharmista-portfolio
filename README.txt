SHARMISTA DEB SUVRA - PERSONAL PORTFOLIO

PROJECT FILES
- index.html    Home page
- about.html    About, education and skills page
- projects.html Projects and contact form page
- style.css     Shared design for all three pages
- profile.jpeg  Your profile photo

IMPORTANT: Keep all five files in the SAME folder. Do not move style.css or
profile.jpeg into a separate folder. Each HTML page links to ./style.css.

OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the extracted sharmista-portfolio folder in VS Code.
3. In VS Code, right-click index.html and choose Open with Live Server,
   or double-click index.html to open it in your browser.
4. Use the Home, About and Projects navigation links to test all pages.

EDITING
- Change page text in the relevant HTML file.
- Change colors, spacing, and layout in style.css.
- To replace your photo, use a new image named profile.jpeg and keep it
  beside the HTML files.
- Replace the sample GitHub, LinkedIn and email links in index.html with
  your real profile links and email address.

TECHNOLOGY
- HTML and CSS only. No JavaScript or frameworks.
- The contact form is a visual front-end form only; it will not send messages
  until connected to a backend or form service.
